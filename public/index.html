localio

a local Twilio: voice, SMS and recordings, on SQLite

Development tool. Nothing here is authenticated — the admin API hands out auth tokens and recordings are served without credentials. Do not deploy it.

Accounts

An account is a credential pair. Paste the sid and token into the application you are testing, and point its Twilio base URL at this server. Name a parent to make a subaccount — a full account with its own sid, token and numbers, which the parent's credentials also open.

API keys

The other credential Twilio accepts: the SK… is the username and its secret the password. Webhooks are still signed with the account's auth token — a key opens the API, it never signs.

Key SIDAccountNameSecret

Phone numbers

A number's webhook URLs are both where a webhook is sent and what its signature is computed over, exactly as at Twilio. Edit them in place.
